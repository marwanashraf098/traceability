“Require photos” off: same tiles, labelled optional; Continue doesn't wait for photos.
  • Add opens the phone's camera / gallery (multiple). HEIC/HEIF is converted to JPEG on the phone before uploading; nothing else is resized there except to keep uploads small.
  • Each photo uploads as soon as it's picked (one at a time per line); Continue also waits for uploads in progress. A removed photo is simply not sent.
  • Thumbnails show the phone's own copy (a data: URL — the returns page already allows data: images), so nothing is fetched back.
  • A quantity-2 line takes one set of 1–3 photos, not one per piece.
