Find your store and connect the official app

For the Shopify card in Settings › Connections. One input that takes a .myshopify.com address or a Shopify admin link. Traced shows the store it found and, once the merchant confirms and the server has checked that the store exists, hands off to Shopify's approval screen through the existing /oauth/initiate flow. There is no website-address lookup in v1; the page uses the light theme and DESIGN.md tokens.

2 · What the merchant can paste

Recognised as they type. The server normalises again (ShopDomainNormalizer)
B1
A .myshopify.com address
With https://, a trailing slash or capitals. Normalised to lowercase.
https://ABC123.myshopify.com/
Store address → abc123.myshopify.com
B2
A Shopify admin link
Copied straight from the address bar. Path and query are ignored.
admin.shopify.com/store/abc123/orders?inContextTimeframe=today
Shopify admin link → abc123.myshopify.com

Mockup only, no app code. Interactions shown as static states. Error texts are the proposed EN copy; AR copy for every string ships with the build. The backend stays the source of truth: the frontend recognition (B1/B2) is a preview; the owner-only resolve endpoint runs ShopDomainNormalizer (lowercase, admin link → handle) and /oauth/initiate normalises again, which also fixes today's capitals bug. The only outbound request is the store check to https://<handle>.myshopify.com/meta.json on the validated host, status only. Merchant-typed domains are never fetched.
