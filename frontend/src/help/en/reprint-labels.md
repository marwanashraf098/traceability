To reprint one piece's label, open the piece in Lookup and press Reprint label. A reprint carries the same barcode the piece already has — no new code is made.

## One piece
1. Scan or type the piece's barcode in **Lookup**.
2. Press **Reprint label**, then **Print**.
3. Remove the old label from the piece before you stick on the new one.

Only owners and managers can reprint. The button works only for pieces that are in the warehouse. Untagged pieces have no barcode yet, so there is nothing to reprint — tag them first ([Tag stock](/help/tag-stock)).

## A whole receiving session
Open the session in **Receiving**. After it is finalized you can press **Print Labels** again, **Reprint** for the whole session, or **Print Barcodes** next to a product for only that product. For a Label & verify session, **Print session labels** prints the same factory labels again.

## Other places you can reprint
- **Scan returns**: **Reprint label** in an open return session, for a returned piece whose label is missing.
- **Transfers**: **Reprint Outstanding Labels** on a transfer prints the labels of the pieces still out.
- **Inventory** › **Untagged**: the **Unused labels** list lets you **Reprint** labels that were printed in a Tag stock session but never used.
- **Receiving** › **Factory runs**: **Reprint** prints the same run labels again — no new labels are made.

## Label size
Go to **Settings** › **Business** › **Labels & printing** › **Label size** and choose **40×25 mm** or **50×25 mm**. Only the owner can change it; managers can see it.
